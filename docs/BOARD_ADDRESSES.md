# Поиск плат с выключенной передачей Tx

В разделе «Адреса плат» есть два отдельных режима:

- **Поиск подключённых плат** читает уже подключённые узлы. Он работает, когда обычная передача J1939 выключена, а ответы UDS разрешены.
- **Мастер адресов** назначает новые адреса платам, подключаемым по одной. Для простого поиска его запускать не нужно.

## Как найти платы

1. Подключить адаптер CAN и включить трассировку.
2. Открыть «Адреса плат».
3. В блоке поиска задать начальный и конечный адреса в HEX. Например, `80`–`8F` включает адреса `0x81`, `0x82`, `0x86`.
4. Нажать «Найти платы». Найденные узлы добавляются в список плат; существующие имена сохраняются.

Поиск читает адрес платы, температуру платы, температуру внешнего датчика и текущий уровень топлива. В таблице видны адрес, имя, показания, состояние и время чтения. Отрицательные температуры и уровень сохраняют знак. Если параметр не поддерживается, показывается прочерк, а не ноль.

**Адреса, калибровка, профиль и режим Tx при поиске не изменяются.** Поиск не открывает расширенную сессию, не выполняет SecurityAccess, не пишет в EEPROM и не отправляет CommunicationControl.

## Автоматическое обновление

- «Повторять поиск» выполняет новые проходы по диапазону, обновляя показания и состав подключённых узлов.
- «Искать при открытии раздела» сохраняет настройку и запускает поиск при следующем открытии «Адресов плат», в том числе после перезапуска программы. Если адаптер ещё не подключён, программа ждёт его готовности.
- «Остановить поиск» завершает текущий запрос и освобождает шину.
- При закрытии раздела поиск останавливается. Известные платы далее проверяются обычным опросом присутствия, когда раздел открыт.

Диапазон и переключатели сохраняются в `config/board_addressing.json`. По умолчанию диапазон `0x80`–`0x8F`, один проход. Допустимы адреса `0x00`–`0xFD`; адрес самой программы пропускается. `0xFE` и `0xFF` не опрашиваются.

Каждый адрес получает физический запрос чтения DID `0x0011`. После правильного ответа читаются `0x003B`, `0x0019` и `0x0018`. Запросы идут последовательно: на молчащем адресе две попытки по 0,6 с, на параметрах одна. Общее ожидание ограничено и при ответах NRC `0x78`.

Поиск выполняется до или после прогона камеры, отдельно от назначения адресов. Запросы используют шину последовательно. Если другой раздел начал обмен, поиск ждёт его завершения, не занимая шину между своими запросами. Прогон нельзя начать до завершения поиска; можно дождаться конца прохода либо остановить поиск.

Результат относится к ответившим адресам. Несколько физических плат с одинаковым адресом этот режим не разделяет. Для назначения разных адресов используется отдельный мастер.
